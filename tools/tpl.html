Program-Env · Results

1,648 repositories, eight domains, one contract.

Every environment is a real GitHub project rebuilt into a sandboxed executable with a black-box test suite. The corpus leans toward developer tools and system utilities, and nearly every subagent is steered toward I/O behaviour.

Cost and quality

136.77B tokens. 72.99% coverage. 404 tests per repository.

Test construction is where the budget goes — 130.83B of all tokens — and it buys suites that cover 72.99% of the gold executable's lines on average (median 81.63%), with 404 retained tests per repository (median 287).

Program-Agent · What the agent does, turn by turn

Under Program-Agent the agent works longer, and more of each turn goes to reading and writing code.

Every agent turn contributes one unit of mass, split across the tool actions it made, summed over the 200 task trajectories of each setting. The fine-tuned model under Program-Agent averages about 1,340 turns per task against 730 under Claude Code, and the share of turns spent probing the gold executable drops as reading and writing rise.
